# Webapp demo — the `webapp` preset

A complete project generated by `fgoths init --preset=webapp`, committed here
so you can read the whole thing without running the generator.

This is the **MVC** architecture: SSR with Templ components + HTMX
interactivity, SQLite storage, and the FGOTHS runtime copied verbatim into
`pkg/runtime/`.

## What to look at

| Path | What it shows |
|---|---|
| [main.go](main.go) | Entrypoint: database, routes, middleware |
| [handlers/](handlers/) | Controllers: pages + HTMX/JSON endpoints |
| [views/](views/) | Templ components (SSR) — `index.templ`, `layout.templ` |
| [models/](models/) | Domain entities |
| [internal/database/](internal/database/) | SQLite connection |
| [migrations/](migrations/) | SQL migrations |
| [pkg/runtime/](pkg/runtime/) | The FGOTHS runtime (verbatim copy) |

## Run

```bash
cd webapp-demo
make run
```

Then open http://localhost:8080 — the counter demo posts over HTMX and swaps
the fragment in place.

## Regenerate from scratch

```bash
fgoths init --name=webapp-demo --preset=webapp
```

Note: `.templ` files are compiled with `templ generate` (the generated
`*_templ.go` files are committed here so the example builds without the
Templ toolchain).
