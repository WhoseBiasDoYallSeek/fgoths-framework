# API demo — the `api` preset

A complete project generated by `fgoths init --preset=api --features=metrics,openapi`,
committed here so you can read the whole thing without running the generator.

This is the **Flat API** architecture: one `main.go`, a `handlers/` package,
opt-in `internal/` feature packages, and the FGOTHS runtime copied verbatim
into `pkg/runtime/`.

## What to look at

| Path | What it shows |
|---|---|
| [main.go](main.go) | Entrypoint: routes, metrics middleware, graceful server |
| [handlers/handlers.go](handlers/handlers.go) | Where your endpoints go |
| [internal/health/](internal/health/) | Liveness/readiness probes |
| [internal/metrics/](internal/metrics/) | Prometheus-compatible in-memory metrics |
| [internal/openapi/](internal/openapi/) | OpenAPI spec + docs endpoint |
| [pkg/runtime/](pkg/runtime/) | The FGOTHS runtime (verbatim copy) |

## Run

```bash
cd api-demo
make run
```

Then:

```bash
curl http://localhost:8080/status
curl http://localhost:8080/health
curl http://localhost:8080/metrics
curl http://localhost:8080/docs
```

## Regenerate from scratch

```bash
fgoths init --name=api-demo --preset=api --features=metrics,openapi
```
