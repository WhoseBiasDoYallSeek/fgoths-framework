# Security Policy

## Supported Versions

FGOTHS follows [Semantic Versioning](https://semver.org). Security fixes are
applied to the latest `main` branch only.

| Version | Supported |
|---|---|
| 1.0.0 (main) | ✅ |
| < 1.0.0 | ❌ |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report it privately via
[GitHub Security Advisories](https://github.com/WhoseBiasDoYallSeek/fgoths-framework/security/advisories/new)
for this repository. If that's unavailable, contact the maintainer
([@WhoseBiasDoYallSeek](https://github.com/WhoseBiasDoYallSeek)) via a private
GitHub message.

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce (a minimal generated project or code snippet helps)
- The affected component (CLI generator, embedded runtime, control plane API, etc.)

## What to expect

- Acknowledgement within 5 business days
- A best-effort assessment and, if confirmed, a fix or mitigation timeline
  communicated back to you before any public disclosure
- Credit in the fix's release notes, unless you prefer to stay anonymous

## Scope

In scope:
- The `fgoths` CLI and code generator (`internal/`)
- The embedded runtime (`pkg/runtime`), including the reverse proxy, JWT/mTLS
  middleware, and the control plane REST API
- Generated project templates (`internal/generator/templates`)

Out of scope:
- Vulnerabilities in third-party dependencies (report those upstream; feel
  free to also let us know so we can track/update the dependency)
- Projects generated by FGOTHS that were subsequently modified by their own
  maintainers
